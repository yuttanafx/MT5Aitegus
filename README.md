# MT5 Signal Hub

เว็บกลางรับสัญญาณ (TradingView webhook หรือ AI ที่ EA ส่งข้อมูลมาให้) แล้วส่งเข้า EA ใน MT5

```
TradingView ─┐                                   ┌─> /api/ea/poll  <── EA (MT5) ดึงคำสั่งทุก 3 วินาที
             ├─> /api/webhook ─> Risk ─> คิว ────┤
EA ─> /api/ai/decide ─> AI เลือกกลยุทธ์ ─> กฎ ─> Risk ─┘   EA ส่งผลกลับที่ /api/ea/report
```

AI เลือก "กลยุทธ์" เท่านั้น ส่วนเงื่อนไขเข้าเทรดเช็กด้วยกฎใน `lib/strategies.ts` ที่ตายตัวและตรวจสอบได้

## 1) ขึ้น Vercel
1. แตก zip แล้ว `git init` → push ขึ้น GitHub
2. Vercel → Add New → Project → เลือก repo → Deploy
3. Vercel → Storage / Marketplace → เพิ่ม **Upstash Redis** แล้วต่อเข้ากับโปรเจกต์ (ได้ตัวแปร URL/TOKEN อัตโนมัติ)
4. Settings → Environment Variables ใส่ตาม `.env.example`
   (อย่างน้อย `ADMIN_KEY`, `EA_API_KEY`, `WEBHOOK_SECRET`) แล้ว Redeploy
   **API key ของ AI ไม่ต้องใส่ใน Vercel** — ใส่ได้ในหน้า Dashboard → การ์ด "ผู้ให้บริการ AI" → ช่อง "API key" (เก็บใน Redis, ไม่ถูกส่งกลับมาแสดงที่เบราว์เซอร์) ถ้าใส่ทั้งสองที่ จะใช้ key จากหน้า Dashboard ก่อน
5. เปิดเว็บ ใส่ `ADMIN_KEY` เพื่อเข้าหน้า Dashboard

ไม่มี Redis ก็รันได้ แต่ข้อมูล (รวมถึง API key ที่กรอกในหน้าเว็บ) อยู่ในหน่วยความจำ จะหายเมื่อฟังก์ชันรีสตาร์ท ใช้ทดสอบในเครื่อง (`npm i && npm run dev`) เท่านั้น

## 2) ติดตั้ง EA
1. คัดลอก `ea/SignalHubEA.mq5` ไปที่ `MQL5/Experts` แล้วคอมไพล์ใน MetaEditor
2. MT5 → Tools → Options → Expert Advisors → ติ๊ก **Allow WebRequest** และเพิ่ม `https://YOUR-APP.vercel.app`
3. ลาก EA ลงกราฟ ตั้ง `ServerUrl`, `ApiKey` (= `EA_API_KEY`), `SignalTF`, `SymbolSuffix` (ถ้าโบรกเกอร์ต่อท้ายชื่อ) และเปิด Algo Trading

## 3) ทดสอบ webhook
```
curl -X POST "https://YOUR-APP.vercel.app/api/webhook?key=WEBHOOK_SECRET" \
  -H "content-type: application/json" \
  -d '{"symbol":"XAUUSD","side":"buy","lot":0.01,"sl":2400,"tp":2430}'
```
TradingView ใส่ URL เดียวกัน (ใส่ `?key=` ต่อท้าย เพราะตั้ง header ไม่ได้) และใส่ JSON ข้างบนเป็นข้อความ alert

## สไนเปอร์: สั่ง BUY/SELL ไม้เดียวจาก Telegram ตามแนวรับ/แนวต้านที่ EA ส่งมา
EA กริด (SmartGold) ส่งค่าเดียวกับปุ่ม "S/R + RR" มาที่เว็บทุก ~60 วินาที (`Sn_PushSec`) ทั้งฝั่ง BUY และ SELL: แนวรับ/ต้านที่ใกล้ราคา, SL (หลังแนว + บัฟเฟอร์ ATR), TP1/TP2/TP3 ตาม RR ที่ตั้งใน `SR_RR1-3`
- Telegram: `/menu` → **🎯 สไนเปอร์** (หรือพิมพ์ `/snipe`) → เลือกคู่เงินที่ EA ส่งมา → เห็นราคา แนวรับ/ต้าน และแผน BUY/SELL พร้อม SL, TP1-3 และ **RR** ของแต่ละ TP → กดปุ่ม BUY/SELL + TP ที่ต้องการ → เลือก lot → ยืนยัน → เข้าคิวเป็นออเดอร์เดียวพร้อม SL/TP
- EA เปิดออเดอร์นี้ด้วย **magic ของสไนเปอร์** (`Sn_Magic`, ค่า 0 = `InpMagicNum` + 100000) กริดจึงไม่นับ ไม่ทับถม ไม่ปิด; ไม่ถูกบล็อกด้วย `AI_BlockWhileOpen` ผลการเปิดแจ้งกลับ Telegram เหมือนออเดอร์อื่น
- กันพลาด: ข้อมูลจาก EA เก่าเกิน 4 นาที = สั่งไม่ได้ (💤), ยืนยันก่อนส่งทุกครั้ง (กดซ้ำไม่ส่งซ้ำ), ถ้าแนวเปลี่ยนระหว่างรอยืนยันจะไม่ส่ง, ฝั่ง EA เช็กราคาสดอีกรอบ (SL/TP ต้องอยู่ฝั่งถูกและไกลกว่า Stops Level ของโบรกเกอร์) แล้วเปิดตามราคาตลาดตอนนั้น, lot จำกัดด้วย `MAX_LOT` ของเว็บและ `Sn_CapLot` ของ EA, หยุดระบบ/ข่าวแรง/ใบอนุญาต มีผลเหมือนออเดอร์อื่น
- ต้องคอมไพล์ EA ใหม่ตาม `ea/SNIPER_EA_EDITS.md` (เพิ่ม `ea/SniperSR.mqh` + แก้ไม่กี่จุด) และ deploy เว็บเวอร์ชันนี้ (มี `/api/ea/sr` ใหม่)
- โควต้า Redis: ต่อ 1 คู่เงินเพิ่ม ~43,000 คำสั่ง/เดือนที่ `Sn_PushSec`=60 (แผนฟรีแนะนำตั้ง 120)

## โควตา Upstash Redis (ถ้าขึ้น "max requests limit exceeded")
ทุกการเรียกเซิร์ฟเวอร์อ่าน/เขียน Redis และ Upstash แผนฟรีให้ **500,000 คำสั่งต่อเดือน** เมื่อเต็ม ทุกอย่างพัง (ล็อกอินไม่ได้) จนกว่าจะอัปเกรดแผนหรือขึ้นเดือนใหม่
- **สาเหตุหลักที่เคยเกิด:** หน้า Dashboard มีบั๊กที่ทำให้ยิงขอข้อมูลซ้ำต่อเนื่องไม่หยุดตราบใดที่เปิดแท็บค้างไว้ (ไม่ใช่ทุก 5 วินาทีตามที่ตั้งใจ) แก้แล้ว: ตอนนี้เรียกทุก 10 วินาที (5 วินาทีเมื่อเปิดเสียงแจ้งเตือน) และ **หยุดเรียกเมื่อแท็บถูกซ่อน** ยกเว้นเปิดเสียงแจ้งเตือนหรือลูกกลมลอยอยู่
- **ลดคำสั่งต่อครั้งลงมาก** (วัดจากตัวทดสอบ นับ 1 อ่าน/เขียน = 1 คำสั่ง): EA ดึงคำสั่ง 3 → 1, Dashboard ของสมาชิก 13 → 3, EA กริดส่งข้อมูล 10 → 1 โดยแคชค่าที่เปลี่ยนไม่บ่อย (ตั้งค่า, ผู้ใช้, key) ไว้ในเซิร์ฟเวอร์ 10–30 วินาที, รวมการอ่านหลายค่าเป็นคำสั่งเดียว และลดการเขียนบันทึก "EA ส่งข้อมูลล่าสุด/แท่งเทียน" เหลือทุก ~2 นาที ผลข้างเคียง: เซิร์ฟเวอร์อื่นที่ทำงานพร้อมกันอาจเห็นการเปลี่ยนค่า (เช่น หยุดระบบ, เปลี่ยนรหัสผ่าน) ช้าไปไม่เกิน 10 วินาที
- **ประมาณการต่อเดือนหลังแก้ (ต่อ 1 EA, ค่าประมาณขณะระบบนิ่ง):** EA ดึงคำสั่ง ~1 คำสั่ง/ครั้ง → `PollSeconds`=3 ได้ ~864,000, =5 ได้ ~518,000, =10 ได้ ~259,000 / EA กริดส่งข้อมูลทุก 60 วินาที ~43,000 ต่อคู่เงิน / Dashboard เปิดดูวันละ 8 ชั่วโมง ~260,000 ต่อคน ดังนั้น **แผนฟรี 500,000 ไม่พอสำหรับผู้ใช้หลายคน** ตัวเลขนี้เป็นค่าประมาณจากการนับในเครื่องทดสอบ ให้ดูกราฟ Usage ในหน้า Upstash หลัง Deploy เพื่อยืนยัน
- **ทางเลือก:** (1) Pay-as-you-go ประมาณ $0.20 ต่อ 100,000 คำสั่ง ตั้งงบสูงสุดต่อเดือน (Budget) ได้ มีอีเมลเตือนที่ 70% และ 90% (2) แผน Fixed ราคาคงที่ (เริ่ม $10/เดือน) ไม่นับจำนวนคำสั่ง เหมาะถ้ามีสมาชิกหลายคนเพราะประมาณการข้างต้นเกินล้านคำสั่งต่อเดือนอยู่แล้ว ตรวจราคาล่าสุดที่ upstash.com/pricing/redis
- **ลูกกลมลอยที่เปิดค้างไว้ก็นับ:** ตอนเปิดลูกกลม ตัวดึงข้อมูลคือหน้าต่างลูกกลม (เรียกทุก 15 วินาที หรือทุก 5 วินาทีถ้าเปิดเสียงแจ้งเตือน) เปิดค้าง 24 ชั่วโมงพร้อมเสียงแจ้งเตือนของสมาชิก ≈ 1.5 ล้านคำสั่ง/เดือน ถ้าไม่ได้ใช้ให้ปิด หรือออกจากระบบ (ออกจากระบบจะปิดลูกกลมและหยุดเรียกทั้งหมด) ส่วน EA และ AI ฝั่งเซิร์ฟเวอร์ทำงานต่อโดยไม่ต้องล็อกอินค้างไว้
- ถ้าอยู่แผนฟรี: ตั้ง `PollSeconds` ของ EA เป็น 10 และ `PushSeconds` เป็น 120–300

## เมื่อ AI ใช้งานไม่ได้: ข้อความ error แสดงครบทุกเจ้า
ระบบลองเจ้าที่เลือกไว้ก่อน แล้วลองเจ้าอื่นที่มี key ตามลำดับ (รวม key ที่ตั้งไว้ใน Vercel Environment Variables เช่น `ANTHROPIC_API_KEY`) ข้อความ "AI ใช้งานไม่ได้: …" จึงแสดงสาเหตุของทุกเจ้าที่ลอง คั่นด้วย `|` เช่น `google: … | anthropic: Your credit balance is too low …` ถ้าไม่อยากให้ลองเจ้าไหน ให้ลบ key ของเจ้านั้นทั้งในหน้า Dashboard และใน Vercel (การลบในหน้า Dashboard ลบเฉพาะ key ที่บันทึกไว้ ไม่ลบค่าใน Vercel)

## กลยุทธ์ตามสภาพตลาด
AI มีหน้าที่แค่ระบุสภาพตลาด (ขาขึ้น / ขาลง / ไซด์เวย์ / ผันผวน / ช่วงข่าว) จากนั้นระบบดึงกลยุทธ์ที่ตั้งไว้สำหรับสภาพนั้นมาตรวจเงื่อนไขเข้าเทรดด้วยกฎตายตัว ผู้ดูแลปรับได้ที่การ์ด "กลยุทธ์ตามสภาพตลาด" (ค่าเริ่มต้น: ขาขึ้น → EMA Pullback Buy, ขาลง → EMA Pullback Sell, ไซด์เวย์ → Range Buy/Sell, ผันผวนและช่วงข่าว → ไม่เทรด) มีกลยุทธ์ Trend Follow เพิ่มให้เลือกด้วย ถ้าติ๊กหลายกลยุทธ์ในสภาพเดียวกัน ระบบเลือกอันที่ผ่านเงื่อนไขก่อน
เพิ่มกลยุทธ์ใหม่ได้ที่ `lib/strategies.ts` (เพิ่มรายการใน STRATEGIES) แล้วจะโผล่ในการ์ดให้ติ๊กอัตโนมัติ

## ใช้กับ EA กริด (Terravolteco SmartGold)
AI ระบุสภาพตลาด แล้ว EA ดึง "โปรไฟล์กริด" (Lot, Lot Mult, Step, Step Mult W/A, Max ไม้, TP, Rec Mult, เปิด/ปิด Buy-Sell) ของสภาพนั้นไปตั้งค่าตัวเอง
1. Dashboard → การ์ด "โปรไฟล์กริดสำหรับ EA กริด" เลือกโปรไฟล์ของแต่ละสภาพตลาดและแก้ตัวเลขได้ แล้วกดบันทึก
2. คัดลอก `ea/SignalHubAI.mqh` ไว้โฟลเดอร์เดียวกับ EA แล้วแทรก 5 บรรทัดใน EA:
   - หลังบรรทัดประกาศ `CChartObjectEdit ebT1S, ...` ใส่ `#include "SignalHubAI.mqh"`
   - ท้าย `OnInit()` ก่อน `return(INIT_SUCCEEDED);` ใส่ `AI_Init();`
   - ต้น `OnDeinit()` ใส่ `AI_Deinit();`
   - ใน `OnTick()` ต่อจากบล็อก Equity SL ใส่ `AI_OnTick();`
   - ใน `OnChartEvent()` ใส่ `if(s=="TVE3_AIBTN") AI_Toggle();`
3. ใส่ `AI_Url` และ `AI_EAKey` (= EA_API_KEY) ในอินพุตของ EA และเพิ่ม URL ใน Tools → Options → Expert Advisors → Allow WebRequest
ปุ่ม "AI Profile" ใต้แผงควบคุมใช้เปิด/ปิด ถ้าปิดคุณคุมค่าเองตามเดิม EA ตั้งค่าใหม่เฉพาะตอนโปรไฟล์เปลี่ยน และถ้า AI ไม่มั่นใจหรือเน็ตหลุดจะคงค่าเดิมไว้ ค่าจากเซิร์ฟเวอร์ถูกจำกัดด้วยเพดาน `AI_Cap*` ใน EA เสมอ ใช้ใน Strategy Tester ไม่ได้ (WebRequest ถูกบล็อก)

## วิเคราะห์แนวโน้มเศรษฐกิจ
ถามในช่อง "คุยกับ AI" ได้เลย เช่น "ทองคำสัปดาห์นี้ได้รับผลจากเฟดยังไง" "เงินเฟ้อสหรัฐแนวโน้มเป็นอย่างไร" ระบบจับคำถามที่เกี่ยวกับเศรษฐกิจ (ดอกเบี้ย เงินเฟ้อ เฟด ดอลลาร์ ทอง น้ำมัน CPI/NFP/GDP ฯลฯ) แล้วส่งให้ AI วิเคราะห์แนวโน้ม โดยอ้างอิง symbol และสภาพตลาดที่ระบบกำลังเทรดอยู่ด้วย คำถามอื่นทำงานเหมือนเดิมทุกอย่าง
- **Google Gemini / OpenAI:** ค้นข้อมูลล่าสุดจากเว็บประกอบการวิเคราะห์ (Gemini ต้องเป็นรุ่นที่ Google Search grounding รองรับ)
- **Anthropic:** SDK เวอร์ชันที่ใช้อยู่ยังไม่มีเครื่องมือค้นเว็บ จึงตอบจากความรู้ของโมเดลและแนบหมายเหตุว่าข้อมูลอาจไม่ล่าสุด
- เป็นคำตอบเชิงวิเคราะห์เท่านั้น **ไม่ส่งผลกับคำสั่งเทรด กลยุทธ์ หรือโปรไฟล์กริด** และไม่ใช่คำแนะนำการลงทุน

## สแกนทุกคู่เงินจาก EA SR Breakout (v2.18) + ให้ AI วิเคราะห์
EA ส่ง **ทุกคู่เงินในตะกร้า** (`InpTradeBasketSymbols` + `Scan_ExtraSymbols`) มาที่ `POST /api/ea/scan` ในคำขอเดียว (ทุก `Scan_PushSec` วินาที ค่าเริ่มต้น 60) ข้อมูลต่อคู่: ราคา bid/ask/สเปรด, ADX/+DI/-DI, ATR และ ATR เทียบค่าเฉลี่ย, EMA เร็ว/ช้า/200, EMA20/50, RSI, ระยะ EMA, กรอบสูง-ต่ำ, ความชัน EMA, จำนวนครั้งที่ราคาตัด EMA, ทิศ TF ใหญ่, แนวรับ/ต้านใกล้สุด และ **ผลจำแนกตามกติกาของ EA**: เทรนขึ้น (`trend_up`) / เทรนลง (`trend_down`) / ไซด์เวย์ (`range`) / ผันผวน (`volatile`)
- **เงื่อนไขจำแนก (ปรับได้ที่อินพุต `Scan_*` ของ EA):** ไซด์เวย์ = โหวต 6 ข้อ (ADX ต่ำ, ATR ต่ำกว่าปกติ, EMA เร็ว-ช้าชิดกัน, กรอบ 30 แท่งแคบ, EMA ช้าราบ, ราคาตัด EMA ช้าบ่อย) ผ่านอย่างน้อย `Scan_SideVotesNeeded` ข้อ / เทรนด์ = ADX ถึงเกณฑ์ + โหวตทิศทาง 5 ข้อ (EMA เร็วเทียบช้า, ราคาเทียบ EMA200, ความชัน, +DI/-DI, TF ใหญ่) ตรงกันอย่างน้อย `Scan_TrendVotesNeeded` ข้อ / ผันผวน = ATR พุ่งแต่ ADX ยังไม่ถึงเกณฑ์ / กึ่งกลาง = คงผลเดิม
- **เลือกคู่ให้ AI วิเคราะห์:** ตั้ง `Scan_AIAnalyze` = true และใส่รายชื่อใน `Scan_AISymbols` (เช่น `XAUUSD,EURUSD`, `ALL` = ทุกคู่) คู่ที่เลือกถูกส่งให้ AI **ในคำขอเดียวต่อรอบ** (ไม่ใช่ทีละคู่) ตามช่วงเวลา "AI check interval" ที่ตั้งในหน้า Dashboard ใช้ผู้ให้บริการ/API key ของบัญชีนั้นเอง (สมาชิกใช้ key ของตัวเอง) AI เห็นข้อมูลดิบทั้งหมด + ผลโหวตของ EA ใช้เป็นข้อมูลประกอบ เห็นต่างได้และต้องบอกเหตุผล พร้อมสรุปภาพรวมทุกคู่
- **ถ้า AI ใช้ไม่ได้ (ไม่มี key / โควตาหมด):** ข้อมูลยังถูกเก็บ ตารางยังแสดงผลจากกติกา EA และมีข้อความบอกสาเหตุ ระบบลอง AI ใหม่ทุก 5 นาที
- **แสดงผล:** การ์ด "คู่เงินที่ EA ส่งมา" ในหน้า Dashboard มีคอลัมน์ ADX และ "ที่มา" (กติกา EA / AI) กดแถวเพื่ออ่านเหตุผลและตัวเลขโหวต `GET /api/ea/scan` (ล็อกอินด้วย `x-admin-key` เหมือนหน้าเว็บ) คืน snapshot ล่าสุดทั้งหมดเป็น JSON
- **โควต้า Redis:** เก็บทั้งชุดเป็นค่าเดียวต่อบัญชี = 1 คำสั่งเขียน/ครั้งที่ EA ส่ง (~43,000/เดือนที่ 60 วินาที ไม่ว่ากี่คู่) การอ่านฝั่ง Dashboard รวมอยู่ใน MGET เดิม ไม่เพิ่มคำสั่ง แผนฟรีแนะนำ `Scan_PushSec` = 120
- **ติดตั้ง:** deploy เว็บเวอร์ชันนี้ แล้วคอมไพล์ `SR_Breakout_TrendStart_EA.mq5` ใหม่ (ใช้ `Hub_Url` / `Hub_EAKey` ชุดเดิม ไม่ต้องตั้ง WebRequest เพิ่ม) ใช้ใน Strategy Tester ไม่ได้ (WebRequest ถูกบล็อก) หมายเหตุ: ถ้าเว็บกำลังเรียก AI EA จะรอตอบได้นานสุด ~15 วินาที (เฉพาะรอบที่ถึงเวลาวิเคราะห์)

## ดึงกราฟจาก EA มาที่เว็บ (ไม่ต้องใช้ TradingView / Pine)
EA ส่งแท่งเทียนปิดล่าสุด (ค่าเริ่มต้น 150 แท่งของ `AI_TF`) มาที่เว็บพร้อมข้อมูลปกติ ใช้ราคาจากโบรกเกอร์ของคุณเอง ไม่ต้องพึ่งแหล่งข้อมูลภายนอก
- หน้า Dashboard มีการ์ด **"กราฟจาก EA"** แสดงแท่งเทียน + EMA20/EMA50 + สภาพตลาดปัจจุบัน (ผู้ใช้เห็นเฉพาะกราฟ symbol ที่บัญชีตัวเองกำลังเทรด)
- Dashboard → "แหล่งสภาพตลาด" → เลือก **"กราฟจาก EA คำนวณเอง"** เว็บจะคำนวณสภาพตลาดจากแท่งเทียนด้วยกฎตายตัว **ไม่เรียก AI** (ไม่เสียค่า AI) แล้วสลับโปรไฟล์กริดให้ EA:
  - ผันผวน: ATR สูงกว่าค่าเฉลี่ย 50 แท่งล่าสุดเกิน 1.8 เท่า
  - ขาขึ้น/ขาลง: ADX(14) ≥ 25 และ EMA20 อยู่เหนือ/ใต้ EMA50
  - ไซด์เวย์: ADX < 20
  - ADX 20-25 คงสภาพก่อนหน้า (กันสลับไปมา) ข่าวแรงยังสั่งหยุดก่อนเสมอ
- ต้องคอมไพล์ EA เวอร์ชันใหม่ (มีอินพุต `AI_Bars`) ถ้าใช้ EA เก่า เว็บไม่ได้รับแท่งเทียน กราฟไม่ขึ้นและ EA คงค่าเดิม
- ตัวเลือก webhook (ด้านล่าง) ยังมีให้ใช้ ถ้าอยากส่งสภาพตลาดจากแหล่งอื่น แต่ไม่จำเป็น

## ดึงแนวโน้มจาก TradingView เอง (ไม่ต้องใช้ Pine / webhook)
Dashboard → "แหล่งสภาพตลาด" → เลือก **ดึงแนวโน้มจาก TradingView เอง** เซิร์ฟเวอร์จะถามค่า ADX / EMA20 / EMA50 ของคู่เงินและ timeframe (ตาม `AI_TF` ของ EA) จากฟีด technicals ของ TradingView โดยตรง แล้วใช้กฎเดียวกับ Pine เดิม (ADX ≥ 25 = เทรนด์ ทิศทางตาม EMA20/EMA50, ADX < 20 = ไซด์เวย์, ระหว่างกลางคงสภาพเดิม) ไม่ต้องเปิดกราฟ ไม่ต้องตั้ง alert และไม่ต้องมี TradingView แบบเสียเงิน
- **เปิดออเดอร์:** EA ตัวเปิดออเดอร์ (`SignalHubEA.mq5`) ใช้โหมดนี้ได้ด้วย: สภาพตลาดจาก TradingView → กลยุทธ์ที่จับคู่ไว้กับสภาพนั้น → เช็กเงื่อนไขด้วยกฎตายตัว (ADX/EMA/RSI จากราคาโบรกเกอร์ของ EA) → ตรวจความเสี่ยง/ข่าว → เข้าคิว → EA เปิดออเดอร์ (SL 1.5 ATR, TP 2.5 ATR) ไม่เรียก AI เลย
- แคช 1 นาทีต่อคู่เงิน/timeframe ไม่ว่าจะมีกี่บัญชี
- ถ้า TradingView ไม่ตอบ จะสลับไปคำนวณจากแท่งเทียนที่ EA ส่งมาโดยอัตโนมัติ
- ตัวแปรเสริม (ไม่ใส่ก็ได้): `TV_EXCHANGES` (ค่าเริ่มต้น `OANDA,FX_IDC,FOREXCOM,CAPITALCOM`), `TV_SYMBOL_MAP` เช่น `{"XAUUSD":"OANDA:XAUUSD"}`
- ฟีดนี้ไม่ใช่ API ทางการของ TradingView อาจเปลี่ยนหรือถูกจำกัดได้ในอนาคต

## ปุ่ม BUY / SELL เปิดออเดอร์แรกจากหน้าเว็บ
Dashboard → การ์ด "เปิดออเดอร์แรกเอง" → ใส่ Symbol (เว้นว่าง = คู่ล่าสุดที่ EA ส่งมา) และ Lot → กด BUY หรือ SELL → ยืนยัน คำสั่งเข้าคิวเดียวกับออเดอร์อื่น (จำกัด lot ด้วย `MAX_LOT`, กันช่วงข่าว, หยุดชั่วคราวได้) แล้ว EA เปิดไม้ภายในประมาณ 3 วินาที โดยใช้ Magic เดียวกับกริด กริดจึงดูแลไม้นี้ต่อ
- ใช้ EA ไฟล์ `Terravolteco_SmartGold_V22_AI_WebOrder.mq5` (มีอินพุต `AI_WebOrders`, `AI_CapWebLot`, `AI_CmdPollSec`)
- แต่ละกราฟรับเฉพาะคำสั่งของ symbol ตัวเอง
- ใช้ EA หลายคู่เงินในบัญชีเดียวได้: การ์ด "คู่เงินที่ EA ส่งมา" แสดงแนวโน้ม/โปรไฟล์/เวลาอัปเดตของทุกคู่ กดแถวเพื่อดูกราฟและเลือกคู่ที่จะสั่ง BUY/SELL (แถวจางและขึ้น "EA เงียบ" = ไม่ได้ส่งข้อมูลเกิน 5 นาที)
- ถ้า EMA50/EMA200 ของกราฟไม่ตรงทิศ กริดจะไม่เปิดไม้ถัวให้ฝั่งนั้น

## ตั้งโปรไฟล์กริดแยกรายคู่เงิน
Dashboard → การ์ด "โปรไฟล์กริดสำหรับ EA กริด" → ช่อง "ตั้งค่าสำหรับ" เลือก "ทุกคู่ (ค่าร่วม)" หรือเลือกคู่ใดคู่หนึ่ง (รายการมาจากคู่ที่ EA ส่งมา) แก้ Lot / Step / TP / Max ไม้ และการจับคู่สภาพตลาด→โปรไฟล์ แล้วกด "บันทึกให้ XXX" คู่นั้นจะใช้ชุดของตัวเอง (ขึ้น ★) ส่วนคู่ที่ไม่ได้ตั้งเฉพาะยังใช้ค่าร่วม กด "ลบชุดเฉพาะ" เพื่อกลับไปใช้ค่าร่วม ตารางคู่เงินจะแสดง "(เฉพาะคู่)" ต่อท้ายโปรไฟล์ที่ใช้อยู่

## ล้างประวัติคิวคำสั่ง
การ์ด "คิวคำสั่งส่งเข้า EA" เก็บประวัติไว้ (สูงสุด 200 รายการต่อบัญชี ไม่ลบเอง) กดปุ่ม "🗑 ล้างประวัติ" เพื่อลบรายการที่เสร็จ/ล้มเหลว/ถูกบล็อก คำสั่งที่ยังรอส่งหรือกำลังส่งจะไม่ถูกลบ

## ส่งสภาพตลาดเข้า webhook (ทางเลือก) (ให้ EA กริดเทรดตามสภาพตลาดจาก TradingView)
1. TradingView → เปิด Pine Editor → วางโค้ดจาก `tradingview/RegimeAlert.pine` → Add to chart (ปรับ ADX/EMA ได้ ใส่เลขบัญชี MT5 ถ้าต้องการให้ใช้กับบัญชีเดียว เว้นว่าง = ทุกบัญชี)
2. Create Alert → Condition เลือกอินดิเคเตอร์นี้ + "Any alert() function call" → Webhook URL = `https://YOUR-APP.vercel.app/api/webhook?key=WEBHOOK_SECRET` (ข้อความปล่อยตามที่สคริปต์สร้างให้)
3. Dashboard → การ์ด "การตัดสินใจล่าสุดของ AI" → **แหล่งสภาพตลาด**: `AI วิเคราะห์เอง` (ค่าเริ่มต้น) / `Webhook ก่อน ถ้าไม่มีใช้ AI` / `Webhook อย่างเดียว (ไม่เรียก AI)`
4. EA กริดจะสลับโปรไฟล์ตามสภาพตลาดที่ได้รับ (ใช้ตารางสภาพตลาด → โปรไฟล์กริดเดิม) ข่าวแรงยังสั่งหยุดก่อนเสมอ

ส่งเองก็ได้ (ไม่ต้องใช้ TradingView): `{"type":"regime","symbol":"XAUUSD","regime":"trend_up","account":"3030514","ttlMin":240}`
- `regime` ใช้ได้: `trend_up`, `trend_down`, `range`, `volatile`, `news` (รับคำเรียกอื่นด้วย เช่น up, down, sideways, bull, bear)
- `account` ไม่ใส่ = ใช้กับทุกบัญชี, `ttlMin` = อายุของสัญญาณ (ค่าเริ่มต้น 120 นาที) ถ้าหมดอายุแล้วไม่มีสัญญาณใหม่ โหมด "Webhook ก่อน" จะกลับไปใช้ AI ส่วนโหมด "Webhook อย่างเดียว" EA จะคงโปรไฟล์ล่าสุด
- ชื่อ symbol ไม่ต้องตรงเป๊ะ ระบบเทียบจาก 6 ตัวแรก (XAUUSD = XAUUSDm = XAUUSD.a) แต่ชื่ออย่าง GOLD เทียบกับ XAUUSD ไม่ได้
- ใช้กับ EA กริดเท่านั้น ไม่มีผลกับ SignalHubEA (ตัวที่ดึงออเดอร์จากคิว)

## หลายบัญชีเทรด (1 ผู้ใช้ = 1 บัญชี MT5 = 1 EA)
- Dashboard (ผู้ดูแล) → การ์ด "ผู้ใช้งาน" → ใส่ชื่อ + **เลขบัญชี MT5** แล้วกด "สร้างบัญชีผู้ใช้" ระบบสร้างให้ 2 อย่าง (แสดงครั้งเดียว กดคัดลอกข้อความส่งให้ผู้ใช้ได้): **รหัสผ่านเข้าเว็บ** และ **EA key**
- ผู้ใช้ใส่ EA key ที่ช่อง `AI_EAKey` (และ `AI_Url`) ใน EA ของตัวเอง EA ส่งเลขบัญชีที่ล็อกอินอยู่ (`x-account`) มาด้วยทุกครั้ง ถ้าไม่ตรงกับเลขที่ผูกไว้เซิร์ฟเวอร์ปฏิเสธ (403) จึงเอา key ไปใช้กับบัญชีอื่นไม่ได้
- เลขบัญชี 1 เลขผูกได้กับผู้ใช้ 1 คนเท่านั้น เปลี่ยนเลขบัญชีหรือกด "รีเซ็ต EA key" แล้ว key เดิมใช้ไม่ได้ทันที
- ข้อมูลแยกตามบัญชี: คิวออเดอร์ การตัดสินใจล่าสุด จังหวะเรียก AI และเสียงแจ้งเตือน ผู้ใช้เห็นเฉพาะบัญชีตัวเอง ผู้ดูแลสลับดูทุกบัญชีได้จากเมนูมุมบน
- ใช้ร่วมกันทั้งระบบ: API key ของ AI ผู้ให้บริการ/โมเดล ช่วงเวลาวิเคราะห์ โปรไฟล์กริด กลยุทธ์ตามสภาพตลาด ปฏิทินข่าว และปุ่มหยุดระบบ (ผู้ดูแลหยุดได้ทุกบัญชีพร้อมกัน) การระบุสภาพตลาดของ symbol/ไทม์เฟรมเดียวกันใช้ผล AI ร่วมกัน จึงไม่เสียค่า AI เพิ่มตามจำนวนผู้ใช้
- `EA_API_KEY` เดิมยังใช้ได้ เป็น "บัญชีหลัก" ของผู้ดูแล ไม่ต้องส่งเลขบัญชี ข้อมูลเดิมไม่หาย
- TradingView webhook: ใส่ `"account":"เลขบัญชี MT5"` ใน JSON เพื่อส่งออเดอร์เข้าบัญชีนั้น ถ้าไม่ใส่จะเข้าบัญชีหลัก เช่น `{"symbol":"XAUUSD","side":"buy","lot":0.01,"account":"3030514"}`
- ต้องคอมไพล์ EA ใหม่ (ทั้ง `SignalHubAI.mqh`/EA กริด และ `SignalHubEA.mq5`) เพราะเพิ่มการส่งเลขบัญชี

## สมาชิกใช้ API ของตัวเอง (จ่ายค่า token เอง) และรีเซ็ตรหัสผ่านเอง
- **AI key แยกรายสมาชิก:** สมาชิกล็อกอินแล้วเข้าการ์ด "ผู้ให้บริการ AI (ของคุณ)" เลือก Claude / GPT / Gemini ใส่ชื่อโมเดลและ API key ของตัวเอง กับตั้ง "ให้ AI วิเคราะห์ทุก ... นาที" ได้เอง ค่า token คิดกับบัญชีผู้ให้บริการ AI ของสมาชิกโดยตรง
- **ไม่ใช้ key ของผู้ดูแลแทนสมาชิกเด็ดขาด:** ทุกการเรียก AI ของบัญชีสมาชิก (ให้ AI จัดสภาพตลาดของ EA, คุยกับ AI, วิเคราะห์ตลาด/เศรษฐกิจ/ข่าว) ใช้เฉพาะ key ของสมาชิกคนนั้น และผลวิเคราะห์ที่ AI ตอบไว้ไม่ถูกแชร์ข้ามบัญชี (ผู้ดูแลที่ใช้ key ของตัวเองยังเป็นอีกบัญชีหนึ่ง) ถ้าสมาชิกยังไม่ใส่ key: AI ของเขาใช้ไม่ได้ และในโหมด "AI วิเคราะห์เอง" EA จะไม่เทรดตามสภาพตลาดจาก AI (การ์ดจะขึ้นแถบเตือน) โหมดแหล่งสภาพตลาดที่ไม่เรียก AI (กราฟจาก EA, TradingView, webhook) ยังทำงานได้ปกติ
- **การเก็บ key:** เข้ารหัส AES-256-GCM ก่อนเก็บใน Redis ด้วยรหัสลับ `KEY_ENC_SECRET` (ถ้าไม่ตั้ง จะใช้ `ADMIN_KEY`) ไม่ถูกส่งกลับมาแสดง เห็นแค่ 4 ตัวท้าย ข้อควรรู้: คนที่คุม environment variables ของเซิร์ฟเวอร์ (ผู้ดูแล) ถอดรหัสได้ในทางเทคนิค และถ้าเปลี่ยนรหัสลับ key ที่เก็บไว้จะอ่านไม่ได้ ต้องให้สมาชิกใส่ใหม่ (แนะนำตั้ง `KEY_ENC_SECRET` แยกจาก `ADMIN_KEY` ตั้งแต่แรกแล้วไม่เปลี่ยน)
- **ผู้ดูแล:** ในตารางผู้ใช้เห็นว่าสมาชิกคนไหนใส่ key แล้ว (ไม่เห็นตัว key) และเมื่อเลือกดูบัญชีสมาชิก การ์ด AI จะเป็นของบัญชีนั้น ปุ่ม "ทดสอบ AI ด้วยข้อมูลตัวอย่าง" ในบัญชีสมาชิกจะใช้ key ของสมาชิกคนนั้น (เสีย token ของเขาเล็กน้อย)
- **รีเซ็ตรหัสผ่านเอง:** สมาชิกล็อกอินแล้วเข้าการ์ด "บัญชีของฉัน" กรอกรหัสผ่านปัจจุบันเพื่อยืนยัน แล้วกด "รีเซ็ตรหัสผ่านของฉัน" ระบบออกรหัสใหม่ที่สุ่มให้และแสดงครั้งเดียว รหัสเดิมใช้ไม่ได้ทันทีและอุปกรณ์อื่นถูกออกจากระบบ EA key และการผูกเลขบัญชี MT5 ไม่เปลี่ยน ตั้งรหัสเองไม่ได้ เพราะระบบระบุตัวผู้ใช้จากรหัสผ่านโดยตรง รหัสที่ตั้งเองอาจซ้ำกับคนอื่นหรือเดาง่าย ถ้าลืมรหัสจนล็อกอินไม่ได้: กด **"ลืมรหัสผ่าน?"** ที่หน้าแรกก่อนล็อกอิน กรอกเลขบัญชี MT5 กับ EA key ส่วนตัว (ตัวเดียวกับที่ใส่ใน EA) ระบบออกรหัสใหม่ให้ทันที ต้องตรงกันทั้งสองอย่างและจำกัดลองผิด 6 ครั้งต่อ 15 นาทีต่อ IP ถ้าไม่มี EA key แล้ว ให้ผู้ดูแลกด "รีเซ็ตรหัสเว็บ" ให้ (ยังไม่มีระบบกู้รหัสทางอีเมล) รหัสผ่านผู้ดูแลคือ `ADMIN_KEY` เปลี่ยนที่ Vercel

## หลายผู้ใช้ และโหมดกลางวัน/กลางคืน
- เข้าด้วย `ADMIN_KEY` = ผู้ดูแล ทำได้ทุกอย่าง และมีการ์ด "ผู้ใช้งาน" สำหรับกดสร้างรหัสผ่านให้ผู้ใช้แต่ละคน (สุ่ม 16 ตัวอักษร แสดงครั้งเดียว กดคัดลอกส่งต่อได้ ลืมรหัสให้กด "รีเซ็ตรหัส" หรือ "ลบ" เพื่อเพิกถอนสิทธิ์)
- ผู้ใช้ทั่วไปดูการตัดสินใจของ AI คิวคำสั่ง และคุยกับ AI ได้ แต่แก้ค่า หยุดระบบ ทดสอบ AI หรือดู API key ไม่ได้
- รหัสผู้ใช้เก็บเป็นค่าแฮชใน Redis (ถ้าไม่มี Redis รายชื่อจะหายเมื่อฟังก์ชันรีสตาร์ท) ล็อกอินผิดเกิน 8 ครั้งใน 10 นาทีจะถูกพักชั่วคราว
- ปุ่ม ☀️/🌙 มุมบนขวาสลับโหมดกลางวัน/กลางคืน ระบบจำค่าไว้ในเบราว์เซอร์

## ตั้งเวลาให้ AI วิเคราะห์
ที่ Dashboard การ์ด "การตัดสินใจล่าสุดของ AI" เลือก "ให้ AI วิเคราะห์ทุก … นาที" (1 นาที – 2 ชั่วโมง) EA จะส่งข้อมูลมาทุก `PushSeconds` (ค่าเริ่มต้น 60 วิ) และเซิร์ฟเวอร์จะเรียก AI เฉพาะเมื่อครบรอบที่ตั้งไว้ ช่วงที่ยังไม่ครบรอบไม่เสียค่า AI
ข้อมูลที่ส่งเป็นแท่งที่ปิดแล้วของ `SignalTF` จึงตั้งถี่กว่าไทม์เฟรมไปก็ได้ข้อมูลเดิม (เช่น M15 ควรตั้ง ≥ 15 นาที)

## เสียงแจ้งเตือนอัตโนมัติ
กดปุ่ม "เสียงแจ้งเตือน" บนหน้า Dashboard (เบราว์เซอร์ต้องมีการคลิก 1 ครั้งก่อนจึงจะพูดได้ และต้องเปิดหน้านี้ค้างไว้) เมื่อ AI ประเมินว่าสภาพตลาดของ symbol เปลี่ยน (เช่น ไซด์เวย์ → ขาขึ้น) จะพูดแจ้งเอง

## วิเคราะห์ตลาดตามคำถาม และสรุปตลาดก่อนเปิดออเดอร์
- **ถามด้วยเสียงหรือกดปุ่ม "วิเคราะห์ตลาดตอนนี้":** AI วิเคราะห์เชิงเทคนิคจากค่าอินดิเคเตอร์ล่าสุดที่ EA ส่งมา (EMA20/EMA50, ADX, RSI, ATR) บอกทิศทาง ความแรงเทรนด์ โมเมนตัม ความผันผวน และบอกอายุของข้อมูล ถ้าถามรวมกับเศรษฐกิจ (เช่น "วิเคราะห์ตลาดทองคำ") จะเริ่มด้วยมุมมองเทคนิคแล้วต่อด้วยปัจจัยเศรษฐกิจ ข้อมูลที่ใช้คือการวิเคราะห์ล่าสุดของคู่ที่ EA ส่งมาล่าสุดเท่านั้น
- **สรุปตลาดก่อนเปิดออเดอร์:** เมื่อเปิด "🔔 เสียงแจ้งเตือน" ทุกครั้งที่มีออเดอร์ใหม่ (จาก AI หรือ TradingView) ระบบจะพูดสรุป: ซื้อ/ขาย คู่เงิน ล็อต สภาพตลาด ADX/RSI/EMA กลยุทธ์ เหตุผล จุดตัดขาดทุน และเป้าหมาย (ถ้าไม่มี SL จะพูดเตือน) ข้อความมาจากข้อมูลที่เก็บไว้กับออเดอร์ ไม่ได้เรียก AI ซ้ำ จึงพูดทันที ถ้าออเดอร์มาจาก TradingView จะแนบการวิเคราะห์ล่าสุดของคู่เดียวกันภายใน 30 นาที ถ้าไม่มีจะพูดว่ายังไม่มีข้อมูลวิเคราะห์
- **หน่วงออเดอร์ให้พูดจบก่อน:** ตั้งได้ที่ "หน่วงออเดอร์ก่อนส่งเข้า MT5" (ค่าเริ่มต้น 15 วินาที, 0 = ไม่หน่วง) การหน่วงเกิดขึ้น **เฉพาะตอนที่เปิดหน้า Dashboard ค้างไว้พร้อมเสียงแจ้งเตือนอยู่** ถ้าไม่มีใครฟังอยู่ ออเดอร์ส่งเข้า MT5 ทันทีเหมือนเดิม ราคาเข้าจริงเป็นราคา ณ ตอนที่ EA ส่งออเดอร์ (ช้าลงตามที่ตั้งไว้) ส่วน SL/TP เป็นระดับราคาเดิม
- เป็นการวิเคราะห์เพื่อประกอบการตัดสินใจ ไม่ใช่คำแนะนำการลงทุน และไม่ได้เปลี่ยนเงื่อนไขเข้าเทรดของระบบ

## ข่าวแรง: แจ้งเตือนและหยุดเทรดก่อนข่าว
ระบบดึงปฏิทินข่าวเศรษฐกิจ (ข่าวที่มีกำหนดเวลา เช่น NFP, CPI, FOMC) มาเก็บไว้ใน Redis แล้วเทียบกับสกุลเงินของคู่ที่เทรด (XAUUSD และดัชนี/น้ำมัน/คริปโต = ข่าว USD, EURUSD = ข่าว EUR และ USD, ฯลฯ) **ตั้งแต่ก่อนข่าว 30 นาที จนถึงหลังข่าว 15 นาที** (ปรับได้ในการ์ด "ข่าวแรง"):
- ออเดอร์ใหม่ทุกทาง (AI และ TradingView) ถูกบล็อก บันทึกเหตุผลไว้ในประวัติคำสั่ง
- AI ไม่ถูกเรียกในช่วงนี้ สภาพตลาดถูกกำหนดเป็น "ช่วงข่าว" (ไม่เทรด)
- EA กริดสลับไปโปรไฟล์ของสภาพตลาด "ข่าว" (ค่าเริ่มต้น Defensive = หยุดเปิดชุดใหม่) ภายในรอบที่ EA ส่งข้อมูลถัดไป (ประมาณ 60 วินาที) และกลับสู่การทำงานปกติหลังข่าวจบ **ไม่ต้องแก้ไข EA**
- เสียงแจ้งเตือน (เมื่อเปิด 🔔): เตือนล่วงหน้าก่อนเข้าช่วงหยุด, แจ้งตอนหยุดเปิดออเดอร์ใหม่, และแจ้งตอนกลับมาเทรด
- ถามได้ เช่น "มีข่าวแรงอะไรใกล้นี้บ้าง" AI จะสรุปข่าว เวลา ค่าคาดการณ์เทียบค่าก่อนหน้า และผลที่น่าจะมีต่อสินทรัพย์ที่เทรด (ข่าวใกล้เข้ามาถูกส่งให้ AI ทุกคำตอบที่เกี่ยวกับการวิเคราะห์ด้วย)
- **ข่าวด่วนที่ไม่มีกำหนดเวลา** (เช่น เหตุการณ์ภูมิรัฐศาสตร์) ระบบคาดล่วงหน้าไม่ได้ ผู้ดูแลกดปุ่ม "หยุดเปิดออเดอร์ใหม่ 30/60/120 นาที" ในการ์ดข่าว (ใช้ได้แม้ปิดการเฝ้าระวังตามปฏิทิน)
- **ข้อจำกัด:** หยุดเฉพาะการเปิดออเดอร์ใหม่ ออเดอร์ที่เปิดค้างอยู่แล้วไม่ถูกปิดหรือเลื่อน SL ให้ ปฏิทินมาจากฟีดสาธารณะที่ไม่เป็นทางการ (ForexFactory) อาจล่มหรือเปลี่ยนรูปแบบ ถ้าดึงไม่ได้ ระบบ **ไม่บล็อกออเดอร์** (ไม่ให้ระบบเทรดหยุดทั้งหมดเพราะปฏิทินล่ม) แต่จะขึ้นแถบเตือนสีแดงในการ์ดข่าว เปลี่ยนแหล่งข้อมูลได้ด้วย environment variable `NEWS_FEED_URLS` (JSON แบบเดียวกัน คั่นหลาย URL ด้วย `,`) ควรเทียบเวลาข่าวกับปฏิทินที่คุณไว้ใจเป็นครั้งคราว

## ลูกกลมลอย (คุยกับ AI แยกหน้าต่าง)
กดปุ่ม "🔔 เสียงแจ้งเตือน" เป็นเปิด ระบบจะเปิดลูกกลมโปร่งแสงลอยขึ้นมา (หรือกดปุ่ม "🔮 เปิดลูกกลมลอย" เองเมื่อไหร่ก็ได้ — ต้องกดเอง 1 ครั้งหลังรีโหลดหน้า เพราะเบราว์เซอร์ไม่อนุญาตให้เปิดหน้าต่างลอยเองโดยไม่มีการคลิก)
- **Chrome / Edge บนคอมพิวเตอร์:** เปิดเป็นหน้าต่างเล็ก Picture-in-Picture ที่ลอยอยู่บนสุดเสมอ ลากแถบด้านบนไปวางทับหน้าต่าง MT5 หรือกราฟได้ ปรับขนาดได้ แตะที่ลูกกลมเพื่อพูดคุย ลูกกลมกระพริบตามสถานะ (ฟัง/ตอบ/แจ้งเตือนอัตโนมัติ) ซิงก์กับหน้า Dashboard ตลอด
- **เบราว์เซอร์อื่น (Firefox, Safari, มือถือ):** ไม่มี Picture-in-Picture จึงแสดงเป็นลูกกลมที่ลากได้ภายในหน้าเว็บนี้เท่านั้น (จำตำแหน่งไว้) แตะเพื่อคุย มีปุ่ม × ปิด
- **ต้องเปิดแท็บ Dashboard ค้างไว้** (ย่อหรือไปอยู่หลังหน้าต่างอื่นได้ แต่ห้ามปิดแท็บ) เพราะการฟัง/พูด/ดึงข้อมูลทำงานในแท็บนั้น ลูกกลมเป็นเพียงหน้าต่างควบคุม
- หน้าต่าง PiP เป็นหน้าต่างของระบบปฏิบัติการ ทำให้โปร่งใสทั้งหน้าต่างหรือเป็นทรงกลมไม่ได้ ตัวลูกกลมเป็นแก้วโปร่งแสงบนพื้นสีเข้ม

## ข้อควรรู้
- **ทดสอบบนบัญชี Demo ก่อนเสมอ** และเริ่มจาก lot เล็ก ระบบนี้เป็นเครื่องมือ ไม่ได้รับประกันกำไร
- `MAX_LOT`, `ALLOWED_SYMBOLS`, ปุ่ม "หยุดส่งคำสั่งทั้งหมด" ทำงานฝั่งเซิร์ฟเวอร์ ส่วนขีดจำกัดขาดทุนรายวันยังไม่ได้ทำ (ต้องให้ EA รายงานกำไร/ขาดทุนกลับมาก่อน)
- ชื่อโมเดลเริ่มต้นใน `.env.example` ตรวจสอบกับเอกสารของแต่ละเจ้าอีกครั้งก่อนใช้ แล้วแก้ผ่านตัวแปร `*_MODEL` หรือในหน้า Dashboard ได้
- EA ดึงทุก 3 วินาที = ประมาณ 28,800 ครั้ง/วัน ถ้าติดโควตาของแพ็กเกจ ให้เพิ่ม `PollSeconds` หรือย้ายส่วน poll ไปเซิร์ฟเวอร์ที่รันตลอด
- คิวเก็บเป็นรายการเดียวใน Redis เหมาะกับบัญชีเดียวและสัญญาณไม่ถี่มาก ถ้าจะรองรับหลายบัญชีให้แยกคิวต่อบัญชี


## แชทบนกราฟ MT5 (ลูกบอล AI) และการแก้ 504
- EA (`Signal_Hub_AI_V3.mq5`) ส่งคำถามที่พิมพ์ใต้ลูกบอลมาที่ `/api/ea/chat` เว็บตอบเป็นข้อความธรรมดา `ok=1` / `reply=...` ใช้สมองเดียวกับแชทบนเว็บ (`lib/chatcore.ts`) พร้อมข้อมูลสดจากกราฟ (ราคา สภาพตลาด โปรไฟล์ กำไรขาดทุน จำนวนไม้) แชทบนหน้าเว็บทำงานเหมือนเดิม
- จำกัดต่อบัญชี: ถามได้ห่างกันอย่างน้อย 5 วินาที และไม่เกิน `EA_CHAT_PER_DAY` ข้อความต่อวัน (ค่าเริ่มต้น 100) เพราะทุกข้อความเสียค่า AI ของบัญชีนั้น
- วิเคราะห์ข่าว/เศรษฐกิจ: ทุกการเรียก AI มีเส้นตายเวลา (`CHAT_BUDGET_MS` ค่าเริ่มต้น 25000 มิลลิวินาที ต่ำกว่าลิมิต 30 วินาทีของฟังก์ชัน) ถ้าค้นข่าวสดช้า ระบบจะตอบแบบไม่ค้นเว็บแทน และถ้ายังช้าจะตอบข้อความแจ้งแทนการเกิด 504 ถ้าใช้ Vercel Pro ปรับ `maxDuration` ใน `app/api/ai/chat/route.ts` และ `CHAT_BUDGET_MS` ให้นานขึ้นได้
- EA รับออเดอร์จากเว็บทาง OnTimer แล้ว (ไม่ต้องรอ tick) ตลาดปิดก็ยังเห็นออเดอร์และแจ้งผลกลับ (โบรกเกอร์จะปฏิเสธถ้าตลาดปิด)

## เชื่อมต่อ Telegram
บอท Telegram ทำ 2 อย่าง: **แจ้งเตือนออเดอร์** (เข้าคิว / เปิดสำเร็จ / ล้มเหลว / ถูกบล็อก / หมดอายุ) และ **คุยกับ AI + ดูสถานะ** ในแชท

1. คุยกับ [@BotFather](https://t.me/BotFather) → `/newbot` → ได้ token
2. Vercel → Environment Variables เพิ่ม
   - `TELEGRAM_BOT_TOKEN` = token จาก BotFather
   - `TELEGRAM_WEBHOOK_SECRET` = สตริงสุ่มยาว 16 ตัวขึ้นไป (A-Z a-z 0-9 _ -)
   - (ไม่บังคับ) `TELEGRAM_CHAT_PER_DAY` = จำนวนข้อความถาม AI ต่อวันต่อบัญชี (ค่าเริ่มต้น 100)
   แล้ว Redeploy
3. ลงทะเบียน webhook ครั้งเดียว:
```
curl -X POST "https://YOUR-APP.vercel.app/api/telegram/setup" \
  -H "x-admin-key: ADMIN_KEY" -H "content-type: application/json" \
  -d '{"action":"set"}'
```
   ตรวจสถานะ: `{"action":"info"}` · ลบ webhook: `{"action":"delete"}` · ให้ทุกแชทล็อกเอาต์: `{"action":"unlink_all"}`
4. เปิดแชทกับบอท พิมพ์ `/login <รหัสผ่านเว็บ>` (ADMIN_KEY หรือรหัสสมาชิก) ข้อความที่มีรหัสผ่านจะถูกลบให้อัตโนมัติ

**ปุ่มกด:** พิมพ์ `/menu` จะได้ปุ่ม 📊 สถานะ · 📋 ออเดอร์ล่าสุด · 🟢 BUY · 🔴 SELL (ผู้ดูแลมี ⏸ หยุด / ▶️ เปิดระบบเพิ่ม) กด BUY/SELL แล้วเลือกคู่เงิน → เลือก lot → กด ✅ ยืนยัน ปุ่ม lot ตั้งได้ด้วย `TELEGRAM_LOTS` (ค่าเริ่มต้น `0.01,0.02,0.05,0.1` และไม่เกิน `MAX_LOT`) **ถ้าตั้ง webhook ไว้แล้ว ต้องเรียก `{"action":"set"}` ซ้ำหนึ่งครั้ง** เพื่อให้ Telegram ส่งการกดปุ่มมาด้วย

คำสั่ง: `/menu` `/buy` `/sell` (เช่น `/buy XAUUSD 0.01 [sl] [tp]` หรือ `/buy 0.01` ใช้คู่ล่าสุดของ AI; ต้องพิมพ์ `/confirm` ใน 2 นาทีก่อนส่งจริง ตั้ง `TELEGRAM_CONFIRM=off` เพื่อข้ามขั้นยืนยัน) `/status` `/orders` `/pause` `/resume` (ผู้ดูแล) `/logout` `/help` และพิมพ์ข้อความธรรมดาเพื่อถาม AI
- **สมาชิก:** ส่งชื่อบอท (@username) ให้สมาชิก แล้วให้พิมพ์ `/login <รหัสผ่านเว็บของตัวเอง>` ในแชทส่วนตัวกับบอท จะเห็นและสั่งได้เฉพาะบัญชีของตัวเอง ใช้ `/pause` `/resume` ไม่ได้
- แต่ละแชทเห็นและได้รับแจ้งเตือนเฉพาะบัญชีที่ล็อกอิน สมาชิกที่ถูกลบ รีเซ็ตรหัสผ่าน (หรือผู้ดูแลเปลี่ยน `ADMIN_KEY`) จะถูกออกจากระบบ Telegram ทันที ต้อง `/login` ใหม่
- ใช้ได้เฉพาะแชทส่วนตัวกับบอท, ล็อกอินผิด 6 ครั้งล็อก 15 นาที
- ถ้าไม่ตั้ง `TELEGRAM_BOT_TOKEN` ระบบทำงานเหมือนเดิมและไม่เพิ่มคำสั่ง Redis
- การแจ้งเตือนเพิ่มคำสั่ง Redis เล็กน้อยต่อเหตุการณ์ออเดอร์ (อ่านรายการแชทแบบแคช 30 วินาที)

### สีและการจัดข้อความใน Telegram
- ปุ่มมีสีตามความหมาย: **เขียว** = ยืนยัน / BUY / เปิดระบบ, **แดง** = ยกเลิก / SELL / หยุดระบบ, **น้ำเงิน** = ปุ่มอื่น, ปุ่ม "‹ กลับ" ไม่ใส่สี (ใช้ฟีเจอร์ `style` ของ Telegram Bot API ใช้ได้กับแอป Telegram ที่อัปเดตหลัง 9 ก.พ. 2026 รุ่นเก่ากว่านั้นจะเห็นเป็นปุ่มธรรมดา) ปิดสีได้ด้วย `TELEGRAM_BUTTON_STYLE=off`
- Telegram ไม่รองรับการเปลี่ยนสีตัวอักษรในข้อความ จึงใช้ตัวหนา, กล่องอ้างอิง (blockquote), `code` และอีโมจิสี (🟢 🔴 ✅ ⛔) แทน ข้อความที่มาจากผู้ใช้หรือ AI ยังเป็นข้อความธรรมดา

### ตั้งค่า EA/กริดผ่าน Telegram (`/settings` หรือปุ่ม ⚙️ ตั้งค่า)
- **ตั้งผ่านปุ่มได้:** ค่าฝั่งเซิร์ฟเวอร์ที่ EA ดึงไปใช้ ได้แก่ โปรไฟล์กริด (Buy/Sell เปิดปิด, Lot เริ่ม, Lot x, Max ไม้, Step, Step W/A, TP, Rec x), การจับคู่สภาพตลาด→โปรไฟล์, ผู้ให้บริการ AI และความถี่วิเคราะห์ ส่วนค่า Input ในตัว EA บน MT5 (ServerUrl, ApiKey, MagicNumber, `AI_Cap*` ...) ตั้งผ่านปุ่มไม่ได้
- **ผู้ดูแล:** แก้ค่ากลางเหมือนหน้า Dashboard (มีผลกับทุกบัญชีที่ไม่ได้ตั้งของตัวเอง) และมีเมนูระบบ: เปิด/ปิดตัวกันข่าว, แหล่งสภาพตลาด
- **สมาชิก:** แก้ได้เฉพาะ "ส่วนที่ทับ" ของบัญชีตัวเอง ค่าที่ไม่ได้แก้ใช้ค่ากลางของผู้ดูแล มีปุ่มรีเซ็ตกลับเป็นค่ากลาง ค่าที่แก้เองมีเครื่องหมาย `*` และในหน้า Dashboard ชื่อโปรไฟล์ของคู่นั้นต่อท้ายว่า "(ของฉัน)"
- **เพดานสำหรับสมาชิก** (ผู้ดูแลปรับได้ใน Vercel): `MEMBER_MAX_LOT` (ค่าเริ่มต้น 1), `MEMBER_MAX_ORDERS` (20), `MEMBER_MAX_LOTMULT` (3) ใช้ทั้งตอนกรอกค่าและตอนส่งค่าให้ EA (ลดเพดานแล้วค่าที่สมาชิกเคยตั้งไว้สูงกว่าจะถูกตัดลงอัตโนมัติ)
- ทุกการแก้โปรไฟล์/การจับคู่ต้องกด ✅ ยืนยัน (หมดอายุ 2 นาที) และ EA ใช้ค่าใหม่ในรอบดึงค่าถัดไป
- ถ้าคู่เงินนั้นผู้ดูแลตั้งโปรไฟล์เฉพาะคู่ไว้ (หน้า Dashboard) ค่าที่สมาชิกแก้จะถูกทับบนโปรไฟล์เฉพาะคู่นั้น ส่วนค่าที่เมนูแสดงคือโปรไฟล์ชุดกลาง
- หน้า Dashboard ยังไม่มีช่องแก้ค่ากริดรายสมาชิก (แก้ผ่าน Telegram เท่านั้น); การตั้งแบบนี้ไม่เพิ่มคำสั่ง Redis ต่อรอบ EA เพราะเก็บรวมกับตั้งค่า AI ของบัญชีที่อ่านอยู่แล้ว

### เมนูหลักของบอท (`/menu`)
เมนูทุกหน้าแก้ข้อความเดิมในที่เดิม (กดแล้วหน้าเปลี่ยน ไม่ไหลเป็นข้อความใหม่)
- **📈 วิเคราะห์แนวโน้ม**: คู่เงิน/ไทม์เฟรมล่าสุด, สภาพตลาด (ขาขึ้น/ขาลง/ไซด์เวย์/ผันผวน/ช่วงข่าว), ความมั่นใจ, กลยุทธ์, ราคา, RSI/ADX, เวลาอัปเดต
  - 🤖 *วิเคราะห์เทคนิคด้วย AI* = ให้ AI อ่านข้อมูลเทคนิคล่าสุด · 🌐 *เทคนิค + เศรษฐกิจ + ข่าว* = เพิ่มภาพเศรษฐกิจและปฏิทินข่าว (ใช้โควต้า AI ของบัญชีนั้น นับรวมกับข้อความถาม AI ต่อวัน `TELEGRAM_CHAT_PER_DAY`)
- **⚙️ ตั้งค่า EA**: ความถี่ AI (5/15/30 นาที/1 ชม.) ทุกคนตั้งของบัญชีตัวเองได้ ส่วน หยุด/เปิดระบบ, แหล่งสภาพตลาด (AI / กราฟ EA / TradingView / webhook / webhook+AI), ข่าวแรง เปิด/ปิด, หน่วงออเดอร์ (ไม่หน่วง/15/30 วินาที) เป็นค่ากลาง **ผู้ดูแลเท่านั้น** และมีทางไปตั้งโปรไฟล์กริด/จับคู่/ผู้ให้บริการ AI ต่อ
- **📊 สถานะ** และ **📋 ออเดอร์ล่าสุด** (มีปุ่มรีเฟรช)
- **🔔 การแจ้งเตือน**: เลือกต่อแชทว่าจะรับ ออเดอร์เข้าคิว / เปิดสำเร็จ / ล้มเหลว-ถูกบล็อก-หมดอายุ / สภาพตลาดเปลี่ยน (ค่าเริ่มต้นเปิดทั้งหมด จำค่าไว้แม้ล็อกอินใหม่)
- หัวเมนูแสดงสถานะ EA (🟢 ออนไลน์ถ้าส่งข้อมูลมาภายใน 5 นาที) และมีปุ่ม BUY / SELL
